# 13: Continuous Dungeon 2K & Cửu Thiên 18-Stage QuestStep Progression, Eve Boss Resolution & Chest Gating

**What to build:** From the dungeon party's perspective, climbing through Giải Cứu 2K (`12911..=12928`) and Chinh Phục Cửu Thiên (`49960..=49969`) executes the authentic `Data/eve.emg` floor boss battles and script chains when `scene_eve_data` is loaded in production runtime, while providing a deterministic `QuestStep` stage-transition fallback when `scene_eve_data` is empty in lightweight integration tests. In both modes, sequential stage progress (`QuestStep(212)` across `1..=18` for 2K, `QuestStep(12309)` across `1..=18` for Cửu Thiên) is enforced and floor reward chests (`20001`) are gated behind the required stage step for that floor.

**Blocked by:** 09: Event Domain Prefactoring, Opcode Constants & Natural Multi-Session Test Flow

**Status:** done

- [x] **Production `Data/eve.emg` Priority:** On dungeon maps `12911..=12928` (Giải Cứu 2K) and `49960..=49969` (Chinh Phục Cửu Thiên), when `data.scene_eve_data` contains the map scene (`Data/eve.emg` loaded at server startup), NPC/door interactions resolve through the Eve script engine (`resolve_npc_event` / `activate`, independent of the global `TS_EVE_EVENTS` flag for these dungeon maps) so that talking to the floor NPC triggers the canonical `eve.emg` Boss battle (`EventPhase::AwaitingBattle`) and post-battle `QuestStep` + floor warp chain.
- [x] **Deterministic Test Fallback (when `scene_eve_data` is empty):** When `data.scene_eve_data` does not contain the floor scene (e.g. `GameData::default()` in integration tests), interacting with the floor transition NPC on 2K floors (`12911..=12927`, e.g. NPC `15313`) or Cửu Thiên floors (`49960..=49968`, e.g. NPC `61210`) validates that the leader's `QuestStep(212)` or `QuestStep(12309)` matches the current floor stage `S`, increments the step to `S + 1`, and warps the party to `map_id + 1` (rejecting out-of-order attempts with a system message).
- [x] **Floor Reward Chest (`20001`) Gating:** Interacting with Floor Reward Chest (`20001`) on Giải Cứu 2K (`12927` requires `QuestStep(212) >= 17`, `12928` requires `QuestStep(212) >= 18`) or Chinh Phục Cửu Thiên (`49960..=49969`, floor `M` requires `QuestStep(12309) >= (M - 49960) + 1`) validates the player's `QuestStep` before distributing rewards; if the required step has not been reached, the chest refuses to open and sends `sys_msg_frame("Chua du dieu kien mo ruong tang nay!")`.
- [x] Integration tests verify both the deterministic stage-transition + chest gating flow (with `GameData::default()`) and `eve.emg` scene resolution on dungeon maps when `scene_eve_data` is populated.
